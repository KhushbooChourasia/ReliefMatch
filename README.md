# ReliefMatch – AI + Quantum-Based Volunteer Allocation for Disaster Relief

## About the Project
ReliefMatch is an AI and quantum-inspired decision-support system designed to improve volunteer allocation during disaster situations. It helps prioritize disaster reports and match available volunteers with tasks based on their skills, location, and availability.

## Key Features
- **AI-Based Urgency Prediction:** Uses a Machine Learning model to estimate disaster urgency based on severity, population affected, and hours since reporting.
- **Volunteer–Task Matching:** Matches volunteers to tasks using skills, location, and availability.
- **Quantum-Based Optimization:** Uses QUBO formulation and QAOA simulation for volunteer allocation.
- **Classical Comparison:** Uses the Hungarian algorithm as a classical optimization baseline.
- **Dashboard:** Provides an interface to view and manage the allocation process.

## Technologies Used
- Artificial Intelligence and Machine Learning
- Random Forest
- Quantum Optimization (QUBO and QAOA simulation)
- Python
- Frontend and Backend Technologies

## Project Structure
- `backend/` – Backend logic, AI models, and optimization modules.
- `frontend/` – User interface and dashboard.

## Objective
To support faster, more organized, and efficient volunteer allocation during disaster relief operations.

## Team
Developed as a four-member academic and hackathon project.

## Note
ReliefMatch is a decision-support prototype. Its predictions and allocations are intended to assist human decision-making.
